# 🍨 つくろう！どうぶつもりの キラキラパフェやさん

小学校低学年のお子さまがブラウザで直感的に楽しく遊べる、クッキング＆パフェタワー物理パズルゲームです！

---

## 🌟 ゲームの特徴

- 🐾 **どうぶつのお客さん**: うさぎさん、くまさん、ねこさんなどの可愛い動物たちが注文しに来ます。
- 🍓 **リアルタイム2D剛体物理演算**:
  - トッピング同士の反発、摩擦、回転、積み重なり、こぼれ落ちをCanvas上でシミュレーション。
  - サブステップ物理演算により、すり抜けや底抜けを防ぎつつ、安定した積み上げを実現。
- 📏 **たかさチャレンジ！**:
  - ものさし目盛り線とリアルタイム高さ計測（cm）。
  - 新記録ファンファーレ＆紙吹雪演出！
- 🏆 **カップアンロックシステム**:
  - クリア回数に応じて「プチカップ」「スタンダード」「トールグラス」「キングパフェ」が解放！
  - 解放状態とクリア回数はブラウザに保存されるので、ページを閉じても続きから遊べます。
- ✓ **ちゅうもん進捗チェック**:
  - おみせやさんモードでは、積み上がった材料が「したから」順に注文と合っているか、注文チップに✓が付いて一目で分かります。
- 🎵 **Web Audio API による効果音・BGM**:
  - 外部音源ファイル不要。ブラウザ標準のWeb Audio APIで生成される温かい木琴風サウンド。
- 🐙 **クスッと笑えるネタ食材**:
  - たこやき、カレーなど、入れるとどうぶつたちのユニークなリアクションが見られます！

---

## 🎮 遊び方

1. `index.html` をブラウザ（Chrome, Edge, Safari等）で直接開くだけで遊べます（サーバー不要）。
2. ゲームモードを選択：
   - **おみせやさん**: どうぶつのお客さんの注文通りにパフェを作ろう！（全3問）
   - **たかさチャレンジ**: どこまで高く積めるか限界に挑戦！新記録を目指そう。
   - **じゆうにつくる**: 好きなトッピングを自由に盛り付けて写真撮影！
3. 下のトッピングボタンをタップすると、上からトッピングが落ちてきます。
